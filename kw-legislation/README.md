# kw-legislation — مرجع التشريعات الكويتية

إضافة Claude تعطي المهارة `kw-legislation`: بحث بالمادة والكلمات في 84 قانوناً ولائحة كويتية، مع عرض صورة الصفحة الأصلية للتحقق قبل أي اقتباس.

## المصدر
- تجميع منشور «التعديلات حتى 5/10/2026»، إعداد: مستشار أول جزاء العتيبي، محكمة الاستئناف.
- النسخة الأصلية (PDF، 1710 صفحة) داخل `source/kuwait-legislation.pdf` بدون تعديل.
- **هذا تجميع مو الجريدة الرسمية.** النصوص الرسمية من «الكويت اليوم». القوانين الصادرة بعد تاريخ التجميع غير موجودة.

## شنو فيه
```
skills/kw-legislation/SKILL.md   تعليمات الاستخدام وقواعد التحقق
scripts/find_article.py          list | article | search | page   (Python 3 فقط)
data/index.json                  فهرس القوانين والمواد (رقم المادة ← صفحة PDF)
data/laws/NNN.txt                نص كل قانون مع علامات الصفحات
source/kuwait-legislation.pdf    الأصل
tools/build_index.py             يعيد بناء data من PDF جديد (يحتاج pdftotext)
```

## ملاحظات الدقة
- النص مستخرج آلياً: يفقد أحياناً حرف «م» داخل بعض الروابط («الأعمال» ← «الأعال»)، لذلك التحقق بصورة الصفحة إلزامي قبل الاقتباس أو الاعتماد على رقم.
- فهرس المواد مبني بقاعدة آلية على ترويسات الصفحات وتسلسل أرقام المواد: كل القوانين تقريباً مفهرسة، لكن بعض الجداول واللوائح (مثل جداول المخدرات) بدون مواد.
- أي رأي قانوني أو استشهاد رسمي يُراجع من النص الرسمي.
