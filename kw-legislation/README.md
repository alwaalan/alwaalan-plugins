# kw-legislation — مرجع التشريعات الكويتية

إضافة Claude تعطي المهارة `kw-legislation`: بحث بالمادة والكلمات في 84 قانوناً ولائحة كويتية، مع عرض صورة الصفحة الأصلية للتحقق قبل أي اقتباس، ومطابقة الأخبار مع المرجع، ومقارنة النسخ.

## المصدر
- تجميع منشور «التعديلات حتى 5/10/2026»، إعداد: مستشار أول جزاء العتيبي، محكمة الاستئناف.
- النسخة الأصلية (PDF، 1710 صفحة) داخل `source/kuwait-legislation.pdf` بدون تعديل.
- **هذا تجميع مو الجريدة الرسمية.** النصوص الرسمية من «الكويت اليوم». القوانين الصادرة بعد تاريخ التجميع غير موجودة. تفاصيل الحقوق في NOTICE.md بجذر المستودع.

## الأوامر (scripts/find_article.py)
| الأمر | وظيفته |
|---|---|
| `list [--grep]` | القوانين المتوفرة وأرقام ملفاتها |
| `article <قانون> <رقم>` | نص المادة وصفحتها وهوامش التعديل |
| `search "كلمات" [--law]` | بحث بالكلمات |
| `page <رقم> [--out]` | صورة الصفحة للتحقق (يحتاج PyMuPDF) |
| `amendments <قانون> [--year]` | المراسيم المعدِّلة وهوامشها |

سكربتات أخرى: `scripts/enrich_news.py` (مطابقة أخبار الداشبورد مع المرجع)، و`tools/diff_versions.py` (الجديد بين نسختين كأخبار مقترحة)، و`tools/build_index.py` (يعيد البناء من PDF جديد، يحتاج pdftotext، ويحفظ `data/index.prev.json`).

## شنو فيه
```
skills/kw-legislation/SKILL.md   تعليمات الاستخدام وقواعد التحقق
scripts/                         find_article.py · enrich_news.py
tools/                           build_index.py · diff_versions.py
data/index.json                  فهرس القوانين والمواد (رقم المادة ← صفحة PDF) وتاريخ المرجع
data/index.prev.json             الفهرس السابق (للمقارنة)
data/laws/NNN.txt                نص كل قانون مع علامات الصفحات
source/kuwait-legislation.pdf    الأصل
```

## ملاحظات الدقة
- النص مستخرج آلياً: يفقد أحياناً حرف «م» داخل بعض الروابط («الأعمال» ← «الأعال»)، لذلك التحقق بصورة الصفحة إلزامي قبل الاقتباس أو الاعتماد على رقم.
- فهرس المواد مبني آلياً على ترويسات الصفحات وتسلسل أرقام المواد. كل القوانين تقريباً مفهرسة، لكن بعض الجداول واللوائح (مثل جداول المخدرات وجدول مخالفات المرور) بدون مواد.
- هوامش التعديل تظهر بصفحتها وقد تخص مادة غير المادة المجاورة.
- أي رأي قانوني أو استشهاد رسمي يُراجع من النص الرسمي.
