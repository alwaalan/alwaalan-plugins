# مرجع التشريعات الكويتية — kw-legislation

**مسار السكربت:** `<base>/../../scripts/find_article.py` (الـ base يظهر أول المهارة). يحتاج Python 3 فقط. لعرض صور الصفحات: `python -m pip install pymupdf`.

## المصدر وحدوده (اقرأها قبل الاستخدام)
- تجميع منشور بعنوان «التعديلات حتى 5/10/2026» إعداد: مستشار أول جزاء العتيبي، محكمة الاستئناف. نسخة الـ PDF الأصلية مرفقة بالإضافة (`source/kuwait-legislation.pdf`، 1710 صفحة).
- **هو تجميع مو الجريدة الرسمية.** النص الرسمي النهائي من «الكويت اليوم».
- **القوانين والمراسيم الصادرة بعد تاريخه ما هي فيه.** لو سُئلت عن قانون صدر بعد 5/10/2026 قل بصراحة إنه خارج المرجع. (قانون الإعلام 102 لسنة 2026 موجود فيه.)
- **النص مستخرج آلياً من PDF**: قد يفقد حروفاً (أبرزها «م» داخل بعض الروابط: «الأعمال» ← «الأعال»، «كما» ← «كا») وقد يشوّش ترتيب الترقيم والأقواس. الفهرس يعتمد على ترويسة الصفحة، وبعض المواد المكررة أو الملغاة قد تُقرأ غلط.

## قاعدة الذهب: لا تعتمد النص بدون صورة الصفحة
النص لـ **إيجاد** المادة وصفحتها. قبل ما تكتب رقم مادة أو تقتبس كلمات أو تعتمد مدة/مبلغ/عقوبة:
1. شغّل `page <رقم الصفحة>` واحفظ الصورة بمجلد مؤقت.
2. افتح الصورة بالقراءة وتأكد من رقم المادة والنص بعينك.
3. لو اختلف النص المستخرج عن الصورة، **الصورة هي الصح**.
4. ما اشتغل عرض الصورة لأن PyMuPDF غير منصّب (الأمر يطلع «لعرض صورة الصفحة ثبّت PyMuPDF»)؟
   - **اطلب إذن المستخدم أولاً** بجملة وحدة: «أحتاج أنصّب مكتبة PyMuPDF عشان أعرض صفحة المادة وأتحقق منها، أنصّبها؟». لا تنصّب بدون موافقته.
   - لو وافق شغّل `python -m pip install pymupdf` (جرّب `py -m pip` أو `python3 -m pip` لو الأول ما اشتغل)، ثم أعد أمر `page`.
   - لو رفض، أو فشل التنصيب، أو ما فيه بايثون: قل له إن التحقق البصري ما تم، ولا تقتبس حرفياً ولا تعتمد رقم مادة أو مبلغ أو مدة، واذكر له صفحة PDF عشان يراجعها بنفسه.

## الأوامر
```bash
python <base>/../../scripts/find_article.py list --grep ايجار          # القوانين المتوفرة وأرقام ملفاتها
python <base>/../../scripts/find_article.py article "قانون الايجار" 20 # نص المادة + صفحة PDF
python <base>/../../scripts/find_article.py search "انتهاء عقد اخلاء" --law "قانون الايجار"   # بحث بالكلمات (كل الكلمات لازم تتواجد)
python <base>/../../scripts/find_article.py page 1098 --out صفحة.png   # صورة الصفحة للتحقق
python <base>/../../scripts/find_article.py amendments "قانون الجنسية الكويتية" --year 2026   # هوامش التعديل: متى وبأي مرسوم تعدّل القانون
python <base>/../../scripts/enrich_news.py --news .legal-carousel/news.json   # مطابقة أخبار الداشبورد مع المرجع
python <base>/../../tools/diff_versions.py --old <data>/index.prev.json --new <data>/index.json   # الجديد بين نسختين
```
- اسم القانون يطابق جزئياً؛ لو طلع أكثر من قانون حدد برقم الملف (مثل `065`).
- البحث يتجاهل الهمزات والتشكيل. جرّب كلمات أقل لو ما طلع شي (الحروف الناقصة بالنص المستخرج قد تكسر الكلمة).

## كيف تجاوب
1. **حدد القانون:** `list --grep` أو من السؤال. لو في أكثر من قانون محتمل (مثلاً الإيجار والمدني) اسأل أو اذكر الاثنين.
2. **افتح المادة** بـ `article`. لو المادة «غير مفهرسة» جرّب `search` بكلمة من موضوعها، أو افتح صفحة قريبة بـ `page`.
3. **تحقق بالصورة** (قاعدة الذهب).
4. **اكتب الجواب** بهالصيغة: اسم القانون ورقمه وسنته (من العنوان الرسمي)، رقم المادة، الخلاصة بكلمات بسيطة، وصفحة PDF للمراجعة. نبّه على التعديلات المذكورة بهامش الصفحة («مضافة/معدلة بموجب القانون رقم…»).
5. **المواد الملغاة** تظهر بالنص «ملغاة»: لا تستشهد بها كأنها ساريّة.
6. **التعديلات:** أمر rticle يطبع هوامش التعديل الموجودة بصفحات المادة، وmendments يلخص كل هوامش القانون (المراسيم المعدِّلة وتكرارها). الهامش يظهر بصفحته وقد يخص مادة غير المجاورة له، فتحقق بصورة الصفحة قبل ما تنسب تعديلاً لمادة معينة.

## ⛔ ممنوع
- كتابة رقم مادة أو نص أو مبلغ ما تحققت منه بصورة الصفحة.
- الاستشهاد بقانون ما هو بالفهرس كأنه من المرجع.
- التخمين لو المادة ما انلقت: قل «ما لقيتها» واقترح طريقة البحث.
- استخدام مصدر خارجي (مواقع، ذاكرة) بدون موافقة صريحة من المستخدم.
- إعطاء رأي قانوني نهائي: هذا مرجع نصوص، والقرار لصاحب الحساب أو المحامي.

## تحديث المرجع بنسخة جديدة
ضع الـ PDF الجديد مكان `source/kuwait-legislation.pdf` وشغّل (يحتاج `pdftotext` من poppler):

بعدها افحص عينة (مادة من قانون الإيجار والعمل والمرور) قبل الاعتماد، وحدّث تاريخ آخر تحديث بهالملف وبالـ README.
