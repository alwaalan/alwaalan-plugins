# تصدير PNG — export-png

السكربت في `<base>/../../scripts/export_slides.py` (الـ base يظهر أول المهارة). يحتاج Python و Chrome أو Edge منصّبين، واتصال انترنت (الخط يتحمل من جوجل).

## الأمر
```bash
python <base>/../../scripts/export_slides.py "<موضوع>/carousel-<slug>.html" --out "<موضوع>" --scale 2 --name "<اسم الموضوع>"
```
- `--scale 2` = 2160×2880 (عالية) و`--scale 1` = 1080×1440 (قياس انستقرام).
- `--only 1,5` لتصدير شرائح معينة بس.
- الأسماء: `<اسم الموضوع> 1.png` … `<اسم الموضوع> N.png`.
- ما لقى المتصفح؟ حدد `CHROME_PATH`.

## بعد التصدير
1. السكربت يتأكد من الأبعاد ويطبع تحذير لو غلط.
2. **افتح بالقراءة** شريحتين على الأقل (الغلاف وأكثف شريحة) وتأكد من: الحروف العربية سليمة (ما فيها مربعات)، الشعار، النص، التذييل.
3. لو الحروف مكسورة ← أعد التصدير (الخط ما تحمل). لا تسلّم ملفات مشكوك فيها.
4. بلّغ المستخدم بأسماء الملفات والدقة، وقل بصراحة اللي فحصته (كم شريحة فتحت بعينك).

## ملاحظات
- الصفحة نفسها فيها أزرار حفظ (شريحة، كل الصور، ZIP) كبديل يدوي.
- لرفع الصور على خدمة نشر: PNG يكبّر الحجم، JPEG بجودة 0.92 أخف بدون فرق مرئي (انستقرام يعيد الضغط).
- ما تنشر شي: التصدير حفظ ملفات محلي بس.
